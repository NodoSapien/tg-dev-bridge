# Plantilla de Reglas para Agentes (ChatOps con Telegram)

Copia este archivo en la raíz de cualquier repositorio de la startup como `.agent-rules.md` o agrégalo a tu `CLAUDE.md`.

---

## 🚀 Notificación Automática de Tareas en Telegram

Al finalizar cualquier feature, bugfix o refactor:

1. **Revisa el trabajo completado:** Agrupa los cambios técnicos y funcionales que realizaste.
2. **Revisa los pasos pendientes:** Lee `TODO.md` o deduce los siguientes pasos de la sesión.
3. **Reporta al equipo:**
   - **Si tienes MCP activo:** Llama a la tool `send_dev_update` con `completedChanges`, `nextSteps` y opcionalmente `blockers`.
   - **Si estás en terminal:** Ejecuta:
     ```bash
     tg-bridge -d "Cambio realizado 1" "Cambio realizado 2" -n "Siguiente paso 1" "Siguiente paso 2"
     ```

### 📦 Otros Bots Disponibles en este Entorno:
- **Release notes:** `tg-bridge --profile release-notes --version "v1.0" --highlights "Novedad 1" "Novedad 2"`
- **Bug report:** `tg-bridge --profile bug-report --severity "Alta" --summary "Error X" --steps-to-reproduce "Paso 1" "Paso 2"`
- **Crear un nuevo bot:** `tg-bridge init <nombre> --preset <dev-update|release-notes|bug-report|custom>`

No necesitas calcular rama, commit ni autor; `tg-bridge` los deduce del contexto de Git de este repositorio.
