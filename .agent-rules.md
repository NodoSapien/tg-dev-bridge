# Reglas de ChatOps para Agentes de Desarrollo (.agent-rules.md)

> **Instrucción para el Agente:** Este repositorio utiliza `tg-bridge` para notificar al equipo en Telegram al finalizar tareas o detectar incidentes. Sigue este protocolo obligatoriamente.

---

## 🚀 Al Finalizar Cualquier Tarea

1. **Revisa los cambios:** Haz un resumen conciso de lo realizado.
2. **Revisa los siguientes pasos:** Consulta `TODO.md` o deduce las tareas lógicas pendientes.
3. **Reporta al equipo:**
   - **Con MCP activo:** Invoca `send_dev_update` con `completedChanges` y `nextSteps`.
   - **En terminal:** Ejecuta:
     ```bash
     tg-bridge -d "Cambio 1" "Cambio 2" -n "Paso siguiente 1" "Paso siguiente 2"
     ```

---

## 🛡️ Política de Seguridad DLP (Data Loss Prevention)

- **CERO SECRETOS:** `tg-bridge` bloquea automáticamente el envío si incluyes tokens de GitHub (`ghp_`), API keys (`sk-`, `AKIA`), JWTs o URLs con contraseñas de bases de datos.
- Nunca expongas credenciales en las viñetas de cambios o siguientes pasos.

---

## 📦 Otros Bots Disponibles

- **Anuncios de Versión:** `tg-bridge --profile release-notes --version "vX.Y" --highlights "Novedad 1" "Novedad 2"`
- **Alertas de Bug:** `tg-bridge --profile bug-report --severity "Alta" --summary "Fallo detectado" --steps-to-reproduce "Paso 1"`
- **Crear un nuevo bot:** `tg-bridge init <nombre> --preset <dev-update|release-notes|bug-report|custom>`
